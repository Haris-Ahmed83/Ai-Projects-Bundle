# Interactive Regex Playground 🚀
> A web application that allows users to test and visualize regular expressions against sample text. Users can input regex patterns and text, then see real-time matches and detailed visualizations.

## Description
This project provides an intuitive web interface for experimenting with regular expressions. It aims to simplify the often complex process of pattern matching by offering immediate visual feedback on how regex patterns interact with various text inputs. Ideal for developers, students, and anyone looking to hone their regex skills or validate patterns effectively.

## Features
*   **Real-time Matching:** Instantly see matches as you type your regular expression and sample text.
*   **Interactive Visualization:** Highlighted matches directly within the text area for clear understanding.
*   **Regex Flags Support:** Option to apply common regex flags like global (`g`), case-insensitive (`i`), and multiline (`m`).
*   **Error Handling:** Provides feedback for invalid regular expression syntax.
*   **Capture Group Display:** Clearly shows identified capture groups and their contents.
*   **Sample Text Examples:** Includes pre-defined text snippets for quick testing and learning.
*   **Clean Interface:** A user-friendly layout focused on clarity and ease of use.
