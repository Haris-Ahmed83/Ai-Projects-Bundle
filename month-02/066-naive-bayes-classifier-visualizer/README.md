# Naive Bayes Classifier Visualizer 🚀
> An interactive web application demonstrating the Naive Bayes classification algorithm. Users can input sample data points and observe how

## Description
This interactive web application provides a clear and intuitive demonstration of the Naive Bayes classification algorithm. Users can actively engage by inputting their own sample data points, allowing them to visualize the algorithm's decision-making process in real-time. It serves as an educational tool to understand how Naive Bayes classifies data based on probabilistic principles.

## Features
*   Interactive canvas for adding and manipulating 2D data points.
*   Real-time visualization of the Naive Bayes decision boundary.
*   Clear color-coding for different data classes and unclassified points.
*   Display of calculated probabilities for new, unclassified samples.
*   Intuitive controls to reset the canvas and start a new simulation.
*   Observe how the classifier adapts and updates its boundary with new input data.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript (ES6+)
*   Canvas API

## Key Concepts Demonstrated
*   **Machine Learning**: Illustrates a fundamental supervised learning algorithm in action.
*   **Classification**: Shows how data points are assigned to predefined categories based on learned patterns.
*   **Probability**: Visualizes the role of conditional probability and Bayes' Theorem in making classification decisions.
*   **Data Visualization**: Presents complex algorithmic behavior and data distribution through interactive graphical elements.
