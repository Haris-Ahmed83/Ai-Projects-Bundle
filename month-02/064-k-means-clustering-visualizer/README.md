# K-Means Clustering Visualizer 🚀
> An interactive web application that allows users to upload a dataset or generate synthetic data, then visualize the K-Means clustering algorithm in action. Users

## Description
This web application provides an intuitive platform to explore the K-Means clustering algorithm. Users can either upload their own CSV datasets or generate various synthetic data distributions. The tool then visually demonstrates how K-Means iteratively groups data points into clusters, offering a clear understanding of its mechanics.

## Features
*   Upload custom CSV datasets for clustering.
*   Generate synthetic datasets with configurable parameters (e.g., number of clusters, noise).
*   Visualize the K-Means clustering process step-by-step.
*   Interactive controls to adjust K (number of clusters) and other algorithm parameters.
*   Real-time display of cluster assignments and centroid movements.
*   Color-coded visualization of data points and their assigned clusters.
*   User-friendly interface for easy exploration of clustering concepts.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript

## Key Concepts Demonstrated
*   **Machine Learning:** Directly implements and visualizes a fundamental unsupervised learning algorithm (K-Means).
*   **Data Visualization:** Employs graphical representations to show data points, clusters, and centroids, making complex data patterns understandable.
*   **Clustering:** Illustrates the core principle of grouping similar data points together based on proximity.
*   **Interactive:** Allows users to control algorithm parameters, upload data, and observe changes in real-time, fostering active learning.
