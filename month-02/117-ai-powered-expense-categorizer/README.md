# AI-Powered Expense Categorizer 🚀
> Develop a web application where users can input their expenses, and an embedded, lightweight

## Description
This web application empowers users to effortlessly manage their finances by automatically categorizing their expenses. It leverages an embedded, lightweight AI model to intelligently assign categories to user-inputted transactions. The project aims to provide a seamless and intelligent way for users to track and understand their spending habits directly within their browser.

## Features
*   **Intuitive Expense Input**: Easily add new expenses with descriptions and amounts.
*   **AI-Powered Categorization**: Automatically categorizes expenses using a lightweight, embedded AI model.
*   **Manual Category Adjustment**: Users can override or fine-tune AI-assigned categories for accuracy.
*   **Persistent Data Storage**: All expense data is saved locally in the browser using Web Storage API, ensuring continuity across sessions.
*   **Real-time Expense List**: View a dynamic list of all entered and categorized expenses.
*   **Client-Side Processing**: All AI and data management happen directly in the browser, ensuring privacy and responsiveness.
*   **Simple & Responsive UI**: A clean user interface designed for ease of use across devices.

## Tech Stack
*   HTML5
*   CSS3

## Key Concepts Demonstrated
*   **AI**: Implemented through the expense categorization logic, enabling intelligent data processing directly in the browser.
*   **Machine learning**: The underlying mechanism for the AI, trained to recognize patterns in expense descriptions and assign appropriate categories.
*   **Data categorization**: The primary function of the application, effectively organizing financial data into meaningful and manageable groups.
*   **Finance**: Directly applied to personal expense tracking and management, providing tools for financial oversight.
*   **Local storage**: Utilized for client-side data persistence, securely storing user expenses and custom categories within the browser.
*   **JavaScript**: The foundational language for the entire web application, encompassing frontend logic, UI interactions, and the embedded AI implementation.
