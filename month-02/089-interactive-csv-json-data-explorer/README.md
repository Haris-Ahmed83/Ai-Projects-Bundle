# Interactive CSV/JSON Data Explorer 🚀
> This project allows users to upload a CSV or JSON file and interactively explore its content. It displays the data in a dynamic, sortable, and filterable table, providing a user-friendly interface for quick data inspection.

## Description
This web application provides a straightforward solution for data exploration. Users can effortlessly upload either a CSV or JSON file, and the project immediately parses and renders the data into an interactive HTML table. It's designed for quick data insights without the need for complex tools or setups.

## Features
*   **File Upload**: Easily upload local CSV or JSON files.
*   **Dynamic Data Display**: Renders uploaded data into a clean, readable HTML table.
*   **Column Sorting**: Click on table headers to sort data ascending or descending.
*   **Row Filtering**: Search and filter table rows based on user input across all columns.
*   **Automatic Parsing**: Intelligently handles both CSV and JSON data formats.
*   **User-Friendly Interface**: Simple and intuitive design for a seamless exploration experience.
*   **Error Handling**: Provides feedback for invalid file formats or parsing issues.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript (Vanilla JS)

## Key Concepts Demonstrated
*   **Data Exploration**: Provides an interactive way to visually inspect and understand dataset content.
*   **File Upload**: Implements functionality for users to select and process local files from their system.
*   **Table Rendering**: Dynamically generates and updates an HTML table based on parsed data, ensuring a structured display.
*   **Sorting**: Enables users to reorder table rows based on the values in specific columns.
*   **Filtering**: Allows users to narrow down displayed data by searching for specific keywords or patterns.
*   **Modern Web Tech**: Leverages core HTML, CSS, and JavaScript for a client-side, dependency-free solution.

## Getting Started
