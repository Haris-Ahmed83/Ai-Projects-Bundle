# Interactive Confusion Matrix Explorer 🚀
> Users can input or paste simple classification results (true labels vs. predicted labels) and see a dynamically generated confusion matrix

## Description
This web application provides an intuitive platform for visualizing classification model performance. Users can easily input or paste their true and predicted labels, and the tool will instantly generate a comprehensive confusion matrix. Beyond just the matrix, it also calculates and displays key performance metrics such as precision, recall, and F1-score, offering a deeper insight into the model's strengths and weaknesses.

## Features
*   **Dynamic Confusion Matrix Generation**: Instantly creates and updates a confusion matrix based on user input.
*   **Simple Data Input**: Allows users to easily input or paste true and predicted classification labels.
*   **Comprehensive Metric Calculation**: Automatically computes and displays precision, recall, and F1-score for each class.
*   **Clear Visual Representation**: Presents the confusion matrix in an easy-to-understand tabular format.
*   **Multi-Class Support**: Handles classification results for binary and multi-class scenarios.
*   **Real-time Updates**: Provides immediate feedback as data is entered or modified.
*   **User-Friendly Interface**: Designed for accessibility and ease of use, even for those new to confusion matrices.

## Key Concepts Demonstrated
*   **Machine Learning**: The project serves as a practical tool for evaluating the performance of machine learning classification models.
*   **Classification**: Directly processes and visualizes the results of classification tasks, highlighting correct and incorrect predictions.
*   **Confusion Matrix**: The central output of the application, visually breaking down prediction performance for each class.
*   **Precision**: Calculated and displayed, demonstrating the accuracy of positive predictions.
*   **Recall**: Calculated and displayed, showing the model's ability to find all positive instances.
*   **F1-score**: Calculated and displayed, representing the harmonic mean of precision and recall, offering a balanced performance metric.
