# Interactive PCA Visualizer 🚀
> Upload a dataset (CSV) and interactively explore how Principal Component Analysis (PCA)

## Description
This web application offers an intuitive platform for understanding Principal Component Analysis (PCA) in action. Users can easily upload their own CSV datasets and instantly visualize the results of PCA, gaining insights into their data's underlying structure and key dimensions. It simplifies the complex process of dimensionality reduction through interactive charts and clear representations.

## Features
*   **CSV Data Upload**: Effortlessly upload your own tabular data in standard CSV format.
*   **Real-time PCA Calculation**: Instantly performs Principal Component Analysis on the uploaded dataset.
*   **Interactive Scatter Plots**: Visualize data points projected onto the principal components with dynamic and interactive charts.
*   **Explained Variance Ratio Display**: Clearly understand the contribution of each principal component to the total variance in your dataset.
*   **Component Selection**: Allows users to select and visualize different combinations of principal components.
*   **User-Friendly Interface**: Designed with a clean and intuitive interface for seamless data exploration and analysis.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript (Vanilla JS for data processing, PCA algorithm, and interactive visualization)
*   Client-side CSV parsing (e.g., custom JS implementation or a lightweight library loaded via CDN)

## Key Concepts Demonstrated
*   **Dimensionality Reduction**: Visually showcases how high-dimensional data can be effectively represented in fewer dimensions while retaining essential information.
*   **Principal Component Analysis**: Provides a practical, interactive demonstration of the PCA algorithm, explaining how principal components are derived and what they represent.
*   **Data Visualization**: Employs interactive charts to make complex PCA results accessible and understandable, allowing users to explore projections and variance.
*   **Feature Engineering**: Helps users understand how principal components can serve as new, uncorrelated features derived from original data, useful for subsequent analysis or modeling.
