## Description
The Geolocation Data Visualizer is a web application designed to transform raw location inputs into dynamic map visualizations. Users can effortlessly enter addresses or geographic coordinates, which are then processed and displayed as interactive markers on a responsive map interface. This tool simplifies the process of understanding and analyzing spatial data by providing a clear, visual representation.

## Features
*   **Multiple Input Formats:** Supports various location inputs, including street addresses, city names, and latitude/longitude coordinates.
*   **Interactive Map Interface:** Utilizes an interactive map powered by Leaflet.js, allowing users to zoom, pan, and explore locations.
*   **Dynamic Marker Placement:** Places distinct markers on the map for each successfully geocoded location.
*   **Marker Popups:** Displays relevant information (e.g., input address, coordinates) in a popup when a marker is clicked.
*   **Clear Map Functionality:** Provides an option to clear all existing markers from the map, allowing for fresh visualizations.
*   **Geocoding API Integration:** Leverages an external geocoding service to convert textual addresses into precise geographic coordinates.
*   **Responsive Design:** Ensures a seamless user experience across various devices and screen sizes.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript
*   Leaflet.js (for interactive maps)
*   OpenStreetMap (for map tiles)
*   Geocoding API (e.g., OpenCage, Nominatim)

## Key Concepts Demonstrated
*   **mapping**: Displaying geographical data effectively on an interactive web map using a robust library.
*   **geospatial data**: Handling, processing, and visualizing location-based information, including conversion between addresses and coordinates.
*   **interactive maps**: Enabling user engagement with the map through features like zooming, panning, and clickable markers with popups.
*   **API integration**: Connecting to and utilizing external web services (like geocoding APIs) to enhance application functionality.
