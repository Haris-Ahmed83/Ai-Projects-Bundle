## Description
This project delivers an intuitive web application designed for exploring various data imputation techniques. Users can easily upload a small dataset containing missing values and interactively apply common strategies like mean, median, mode, zero, or a custom specified value. The tool provides immediate visual feedback, enabling a clear comparison between the original and imputed data distributions to better understand the impact of each approach.

## Features
*   **Dataset Upload**: Easily upload small CSV or similar structured datasets directly in the browser.
*   **Multiple Imputation Methods**: Apply mean, median, mode, zero, or a user-defined custom value for missing data.
*   **Interactive Visualization**: Visually compare original data distributions with imputed data using dynamic charts.
*   **Real-time Feedback**: Observe the effects of selected imputation strategies immediately upon application.
*   **Column-Specific Imputation**: Apply different imputation methods to individual columns based on their data type.
*   **Missing Value Identification**: Clearly highlight and identify missing entries within the uploaded dataset.
*   **Download Imputed Data**: Option to download the processed dataset after imputation for further analysis.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript (Vanilla JS for all interactivity and data handling)

## Key Concepts Demonstrated
*   **Data Preprocessing**: Understanding the initial steps required to clean and prepare data for analysis.
*   **Missing Data**: Exploring the common problem of incomplete datasets and its implications.
*   **Imputation Strategies**: Practical application and comparison of various methods to fill in missing values.
*   **Data Visualization**: Using visual aids to represent data distributions and the impact of processing steps.
