# Genetic Algorithm Solver Visualizer 🚀
> Visualize how a genetic algorithm iteratively solves a simple problem, such as finding the optimal path in a maze or reaching a target string. Users can set parameters

## Description
This interactive web application provides a clear visual representation of how genetic algorithms operate. It allows users to observe the evolutionary process as an algorithm iteratively refines solutions to simple problems, offering an intuitive understanding of this powerful optimization technique. Users can experiment with various parameters to see their impact on the algorithm's performance and convergence.

## Features
*   **Multiple Problem Scenarios**: Choose between classic problems like finding an optimal path in a maze or evolving a target string.
*   **Customizable Parameters**: Adjust key genetic algorithm settings such as population size, mutation rate, and crossover rate.
*   **Real-time Iteration Visualization**: Watch the algorithm evolve solutions generation by generation, with visual feedback on progress.
*   **Performance Metrics Display**: Track the best fitness score, average fitness, and current generation count as the algorithm runs.
*   **Interactive Controls**: Pause, resume, reset, and step through generations to analyze the algorithm's behavior at different stages.
*   **Adjustable Simulation Speed**: Control the pace of the visualization to either quickly see results or deeply observe each step.
*   **Dynamic Problem Setup**: Define custom mazes or input your own target strings to challenge the algorithm.

## Key Concepts Demonstrated
*   **Genetic Algorithms**: Directly illustrates the core mechanics including selection, crossover, mutation, and population management.
*   **Optimization**: Visually showcases the iterative process of finding the best possible solution to a given problem.
*   **Evolution**: Demonstrates how solutions improve over successive generations, mimicking natural selection and adaptation.
*   **Visualization**: Provides a clear and engaging graphical interface to understand complex algorithmic processes.
