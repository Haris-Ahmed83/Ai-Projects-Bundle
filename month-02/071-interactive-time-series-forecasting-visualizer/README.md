# Interactive Time Series Forecasting Visualizer 🚀
> Upload or input time-series data and apply various forecasting models (e.g., moving average, exponential smoothing) to predict

## Description
This project offers an interactive web application designed for exploring time series forecasting. Users can easily upload their own datasets or input time-series data directly into the browser. The application then allows for the application of various classic forecasting models, visualizing predictions and enabling comparative analysis.

## Features
*   **Flexible Data Input**: Seamlessly upload time-series data via CSV files or manually input data points directly within the interface.
*   **Multiple Forecasting Models**: Apply and compare different forecasting techniques, including Simple Moving Average and Exponential Smoothing.
*   **Interactive Visualizations**: Dynamically display historical data, model forecasts, and confidence intervals through engaging, interactive charts.
*   **Parameter Tuning**: Adjust model-specific parameters (e.g., window size, smoothing factors) in real-time to observe their immediate impact on predictions.
*   **Comparative Analysis**: Easily evaluate and contrast the performance of different forecasting models on the same dataset.
*   **User-Friendly Interface**: An intuitive and responsive web-based interface designed for accessibility and ease of use.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript

## Key Concepts Demonstrated
*   **Time Series**: Handling, parsing, and visualizing sequential data points collected over time.
*   **Forecasting**: Implementing and applying algorithms to predict future values based on past observations.
*   **Machine Learning**: Utilizing classical statistical learning models (e.g., moving average, exponential smoothing) for predictive analysis.
*   **Data Visualization**: Presenting complex time-series data and model outputs clearly through graphical representations.
*   **Interactive Charts**: Enabling dynamic exploration, zooming, and panning of visualized data for deeper insights.
