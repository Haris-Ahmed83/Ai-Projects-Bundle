# Interactive Data Normalization Visualizer 🚀
> Upload a small dataset (or use a sample) and visualize the impact of different data

## Description
This web application provides an interactive platform to understand the crucial concept of data normalization and scaling. Users can upload their own small datasets or utilize provided samples to visually explore how different normalization techniques, such as Min-Max scaling and Z-score standardization, transform data distributions. It's designed to illustrate the impact of these preprocessing steps on data, which is vital for many machine learning algorithms.

## Features
*   **Dataset Upload**: Easily upload small datasets in common formats (e.g., CSV) for analysis.
*   **Sample Datasets**: Access pre-loaded sample datasets to quickly experiment with the visualization.
*   **Original Data Visualization**: View the distribution of your raw, unnormalized data.
*   **Multiple Normalization Methods**: Apply and compare the effects of Min-Max Scaling and Z-score Standardization.
*   **Interactive Visual Comparison**: See side-by-side or overlaid visualizations of data before and after normalization.
*   **Column Selection**: Choose specific numerical columns from your dataset to normalize and visualize.
*   **Clear Impact Illustration**: Understand how normalization affects data range, distribution, and potential outliers.
