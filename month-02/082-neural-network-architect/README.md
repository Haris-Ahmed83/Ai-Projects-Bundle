## Description
Neural Network Architect is an interactive web application designed to empower users to construct and experiment with custom neural network architectures directly in their browser. It provides an intuitive interface for defining various layers, selecting activation functions, and then training these networks on sample data, offering a hands-on approach to understanding deep learning principles.

## Features
*   **Interactive Network Design:** Visually add, remove, and configure different types of layers (e.g., dense, input, output) to build a custom neural network.
*   **Configurable Layer Properties:** Define neuron counts, activation functions (e.g., ReLU, Sigmoid, Tanh, Linear), and input shapes for each layer.
*   **Real-time Model Training:** Train the designed neural network on provided sample datasets directly within the application, observing the learning process.
*   **Performance Visualization:** Observe training progress through real-time updates of loss curves and other relevant metrics.
*   **Data Visualization:** Visualize input data and the network's predictions, helping to understand how the model processes information and learns patterns.
*   **Experimentation Sandbox:** Easily modify network parameters, architecture, and re-train to compare different approaches and their impact on performance.
*   **In-Browser Execution:** All neural network computations and training are performed locally in the user's browser using TensorFlow.js.

## Tech Stack

## Key Concepts Demonstrated
*   **Machine Learning:** Users engage in the fundamental process of defining models and training them on data to make predictions.
*   **Neural Networks:** The core focus, allowing users to build, configure, and understand the structure and function of artificial neural networks.
*   **Deep Learning:** By enabling the creation of networks with multiple hidden layers, the project illustrates principles central to deep learning.
*   **TensorFlow.js:** Showcases the power and capabilities of running machine learning models entirely within a web browser.
*   **Data Visualization:** Presents input data, network structures, and training results graphically for easier comprehension.
*   **Interactive UI:** Provides a dynamic and responsive user interface that facilitates intuitive design and real-time feedback on network performance.
