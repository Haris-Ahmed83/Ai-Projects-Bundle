## Description
This project delivers an interactive web tool designed to effectively visualize data flow using Sankey diagrams. It allows users to input structured data, which is then transformed into a dynamic and insightful graphical representation of flows and their magnitudes. The visualizer helps in understanding complex distributions and transfers within a system.

## Features
*   **Dynamic Sankey Diagram Generation**: Automatically renders a Sankey diagram from user-provided structured data.
*   **Interactive Nodes & Links**: Hover over nodes and links to reveal detailed information such as source, target, and flow magnitude.
*   **Zoom & Pan Functionality**: Explore intricate diagrams with intuitive zoom and pan capabilities.
*   **Customizable Diagram Layout**: Adjust various parameters like node width, padding, and link colors for better readability and aesthetics.
*   **Data Input Flexibility**: Supports inputting data directly via a text area or potentially loading from predefined examples.
*   **Responsive Design**: Ensures a consistent and user-friendly experience across different screen sizes.
*   **Error Handling**: Provides clear feedback for invalid or malformed input data to guide users.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript (ES6+)
*   D3.js (for data-driven document manipulation and visualization)

## Key Concepts Demonstrated
*   **Data Visualization**: Effectively transforms raw data into a graphical representation (Sankey diagram) to convey insights about data flow and distribution.
*   **D3.js**: Leverages the powerful D3.js library to create highly customizable, dynamic, and interactive SVG-based visualizations.
*   **Data Flow Analysis**: Provides a clear visual model for analyzing how quantities flow between different entities or stages within a system.
*   **Interactive UI**: Implements a user-friendly interface that allows for direct manipulation, exploration, and customization of the visualized data.
