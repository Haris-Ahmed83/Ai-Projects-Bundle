# Decision Tree Visualizer 🚀
> Construct an interactive web application that visualizes the step-by-step process of building a decision tree. Users can provide simple datasets to see how

## Description
This interactive web application provides a clear, step-by-step visualization of how a decision tree model is constructed. Users can input simple datasets to observe the splitting process, understand impurity reduction, and see the resulting tree structure, making complex machine learning concepts accessible. It aims to demystify the internal workings of decision trees through an intuitive visual interface.

## Features
*   Interactive input interface for providing simple datasets.
*   Step-by-step visualization of the decision tree building process.
*   Clear visual representation of data splits at each node.
*   Display of impurity metrics (e.g., Gini impurity, entropy) at each step.
*   Visualization of the final decision tree structure and decision paths.
*   Ability to trace how individual data points navigate the tree.
*   Focus on demonstrating classification tasks with visual clarity.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript (ES6+)

## Key Concepts Demonstrated
*   **Machine Learning:** Illustrates a fundamental supervised learning algorithm in action.
*   **Data Visualization:** Employs visual methods to represent complex algorithmic processes and data splits effectively.
*   **Decision Trees:** Directly visualizes the core mechanics, structure, and decision-making process of decision tree models.
*   **Classification:** Shows how decision trees are used to categorize data points into predefined classes based on their features.
