# Interactive Data Normalization Visualizer 🚀
> An interactive web application that allows users to input a simple dataset and visually explore the effects of common data normalization techniques.

## Description
This interactive web application provides a hands-on platform for understanding fundamental data normalization techniques. Users can input a simple numerical dataset and visually explore the effects of different scaling methods, gaining clarity on how data preprocessing impacts distribution and range. It serves as an excellent educational tool for grasping key concepts in data preparation.

## Features
*   **Simple Data Input:** Easily input numerical data for immediate processing and visualization.
*   **Multiple Normalization Methods:** Apply Min-Max Scaling and Z-Score Normalization with a click.
*   **Real-time Visualization:** Instantly view side-by-side comparisons of raw and normalized data distributions.
*   **Interactive Charts:** Explore data transformations through dynamic and engaging visual representations.
*   **Clear Statistical Overview:** Understand the impact of normalization with accompanying statistical summaries (e.g., min, max, mean, standard deviation).
*   **Intuitive User Interface:** A user-friendly design ensures easy navigation and interaction for learners.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript (Vanilla JS for interactive logic and visualization)

## Key Concepts Demonstrated
*   **Data Preprocessing:** Understanding the initial steps required to prepare data for analysis or machine learning models.
*   **Normalization:** The process of scaling data to a standard range or distribution.
*   **Scaling:** Adjusting the range of features to a common scale.
*   **Min-Max Scaling:** Rescaling features to a fixed range, typically 0 to 1.
*   **Z-Score Normalization (Standardization):** Rescaling features to have a mean of 0 and a standard deviation of 1.
*   **Data Visualization:** Effectively presenting data transformations and their impacts through graphical means.
