# Reinforcement Learning Grid World 🚀
> Create an interactive grid-based environment where a simple agent learns to navigate

## Description
This project presents an interactive web-based simulation of a Grid World, a classic environment for demonstrating reinforcement learning principles. Users can observe a simple agent learn to navigate a grid, avoiding obstacles and finding a goal state, all through a simplified Q-learning algorithm. It offers a hands-on visualization of how an agent iteratively improves its policy to achieve optimal behavior.

## Features
*   **Interactive Grid Display:** Visualize the agent's environment, including start, goal, and obstacle cells.
*   **Agent Movement Visualization:** Watch the agent explore and learn within the grid in real-time.
*   **Configurable Environment:** Easily define grid dimensions, agent start position, goal, and obstacles.
*   **Q-Table Visualization:** Observe the Q-values update for each state-action pair as the agent learns.
*   **Learning Controls:** Start, pause, and reset the learning process to experiment with different parameters.
*   **Performance Metrics:** Track episodes completed and cumulative rewards to gauge learning progress.
*   **Simplified Q-learning Implementation:** A clear and accessible demonstration of the core Q-learning algorithm.

## Key Concepts Demonstrated
*   **Reinforcement Learning:** The fundamental process where an agent learns an optimal policy through trial and error interactions with an environment.
*   **Agent Simulation:** The digital representation and behavioral modeling of an autonomous entity interacting within a defined environment.
*   **Q-learning (simplified):** An off-policy, model-free reinforcement learning algorithm used to find an optimal action-selection policy for a given finite Markov Decision Process.
*   **Grid Visualization:** The graphical representation of a state-space as a grid, providing an intuitive understanding of the agent's movement and environmental interactions.
