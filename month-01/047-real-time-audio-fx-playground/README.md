# Real-time Audio FX Playground 🚀
> An interactive web application allowing users to upload audio files or use microphone input to

## Description
This project is an interactive web application designed to empower users with real-time audio manipulation capabilities. It allows users to either upload existing audio files or capture live input from their microphone, then apply a suite of dynamic sound effects and visualize the audio waveform and frequency spectrum. The aim is to provide a playful yet insightful platform for exploring the power of the Web Audio API and real-time digital signal processing directly within the browser.

## Features
*   Upload local audio files (e.g., MP3, WAV) for processing.
*   Capture live audio input directly from the user's microphone.
*   Apply a diverse range of real-time audio effects, such as reverb, delay, distortion, pitch shift, and equalization.
*   Visualize audio data through dynamic waveform and frequency spectrum displays.
*   Interactive controls to adjust effect parameters and fine-tune the sound.
*   Seamless playback, pause, and stop functionality for both uploaded and live audio.
*   Responsive user interface for an engaging and intuitive experience.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript (Vanilla JS)
*   Web Audio API

## Key Concepts Demonstrated
*   **Web Audio API:** Extensive utilization for creating audio contexts, managing source nodes (media element, microphone), and sophisticated audio routing through various audio processing nodes.
*   **Audio Visualization:** Implementation of techniques to graphically represent real-time audio data, including dynamic waveform rendering and frequency spectrum analysis using `AnalyserNode`.
*   **Sound Effects:** Development and integration of various digital audio effects (e.g., `GainNode`, `BiquadFilterNode`, `DelayNode`, `ConvolverNode`) for real-time manipulation.
*   **Real-time Processing:** Handling of audio streams and application of effects with minimal latency, providing an immediate interactive experience for users.
