# Decision Matrix Tool 🚀
> A web application that helps users make informed decisions by allowing them to list options and criteria. Users can assign weights

## Description
This interactive web application provides a structured approach to decision-making. Users can define multiple options and a set of criteria relevant to their choice, then assign importance weights to each criterion. The tool calculates weighted scores for each option, presenting a clear, data-driven recommendation.

## Features
*   Define and manage a list of decision options.
*   Add and customize various evaluation criteria.
*   Assign importance weights to each criterion to reflect priorities.
*   Score each option against the defined criteria.
*   Automatically calculate weighted scores for all options.
*   Visualize comparative results to aid in final decision-making.
*   Dynamic and interactive user interface for intuitive input and analysis.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript

## Key Concepts Demonstrated
*   **Decision Making**: Provides a systematic framework for evaluating choices based on defined parameters.
*   **Criteria Weighting**: Allows users to prioritize criteria by assigning numerical weights, influencing the overall outcome.
*   **Data Visualization**: Presents calculated scores and comparisons in a clear, digestible format (e.g., tables or simple charts).
*   **Interactive UI**: Offers a dynamic and responsive user experience for inputting data and viewing real-time results.
