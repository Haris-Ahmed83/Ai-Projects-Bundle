# Interactive Regex Tester & Explainer 🚀
> This project allows users to input regular expressions and test strings, instantly highlighting all matches.

## Description
This interactive web application provides a user-friendly interface for testing and explaining regular expressions. Users can input a regex pattern and a target string, and the application immediately processes and highlights all occurrences that match the pattern, making it an excellent tool for learning and debugging regex.

## Features
*   **Real-time Matching:** Instantly highlights all matches as you type in the regex or test string fields.
*   **Interactive Highlighting:** Visually emphasizes all matched substrings within the test string for clear understanding.
*   **Dedicated Input Fields:** Separate areas for entering your regular expression pattern and the text you want to test against.
*   **Regex Flag Support:** Allows for the application of common regular expression flags (e.g., global, case-insensitive).
*   **Match Count Display:** Shows the total number of matches found for the given pattern.
*   **Error Handling:** Provides feedback for invalid regular expression syntax.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript (Vanilla JS)

## Key Concepts Demonstrated
*   **Regular expressions:** Central to the project's functionality, enabling pattern matching and text extraction.
*   **Text processing:** Involves manipulating and analyzing string data to find and highlight specific patterns.
*   **Developer tools:** Serves as a utility designed to assist developers in understanding, testing, and debugging regular expressions.
*   **Client-side JS:** All application logic and UI interactions are handled directly in the browser using JavaScript, without a server-side component.
