# Interactive Linear Regression Fitter 🚀
> Build an interactive web tool where users can click on a canvas to plot data points. The application will then automatically calculate and display the best-fit

## Description
The Interactive Linear Regression Fitter is a dynamic web application designed to visually demonstrate the principles of linear regression. Users can interactively plot data points on a canvas, and the tool will instantly calculate and render the corresponding best-fit line. This project offers a hands-on approach to understanding how a line can best represent a given set of data.

## Features
*   **Interactive Data Point Plotting:** Click on the canvas to dynamically add and plot new data points.
*   **Real-time Linear Regression Calculation:** Automatically computes the best-fit line using the least squares method as data points are added.
*   **Dynamic Visualization:** Instantly displays both the plotted data points and the calculated linear regression line on the canvas.
*   **Clear Canvas Functionality:** Easily reset the plotting area to begin a new regression analysis.
*   **Direct Concept Demonstration:** Offers a hands-on way to visualize the relationship between data points and their linear trend.

## Tech Stack
*   HTML5
*   CSS3
*   Vanilla JavaScript

## Key Concepts Demonstrated
*   **Linear Regression:** The core statistical method for modeling the relationship between a dependent variable and one or more independent variables.
*   **Data Visualization:** Techniques used to present data graphically, enabling users to understand complex data and identify patterns.
*   **Least Squares:** The mathematical optimization technique used to find the best-fit line by minimizing the sum of the squares of the residuals.
*   **Vanilla JavaScript:** Demonstrates client-side scripting prowess using plain JavaScript, without external libraries or frameworks.
