Naive Bayes Classifier Explainer

This interactive tool visually demonstrates the Naive Bayes classification algorithm. Naive Bayes is a probabilistic machine learning algorithm used for classification tasks. It's based on Bayes' Theorem with an assumption of independence among predictors (features). Here, we classify 2D data points into two classes (A or B) based on their X and Y coordinates.

How it works:

  1. Training: Add data points belonging to Class A or Class B. The algorithm learns the probability distribution (mean and standard deviation for X and Y) for each class.
  2. Classification: Input a new point. Naive Bayes calculates the probability that this new point belongs to Class A versus Class B, based on the learned distributions and the prior probabilities of each class.
  3. Assumption: It assumes that the X and Y features are independent given the class.
