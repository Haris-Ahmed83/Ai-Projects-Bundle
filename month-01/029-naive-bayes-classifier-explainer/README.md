# Naive Bayes Classifier Explainer 🚀
> An interactive web application that visually explains the Naive Bayes classification algorithm. Users can input data points or define

## Description
This interactive web application provides a clear and intuitive visual explanation of the Naive Bayes classification algorithm. Users can actively engage by inputting custom data points or defining dataset parameters to observe how the algorithm processes information. It aims to demystify the underlying probabilistic principles and decision-making process of Naive Bayes through dynamic visualizations.

## Features
*   Interactive input for custom data points or dataset generation.
*   Dynamic visualization of data distribution for different classes.
*   Real-time display of calculated probabilities (likelihoods, posteriors).
*   Visual representation of the Naive Bayes decision boundary.
*   Ability to classify new, unseen data points instantly.
*   Clear and concise explanation of each step in the classification process.
*   User-friendly interface for an engaging learning experience.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript (ES6+)

## Key Concepts Demonstrated
*   **Machine Learning**: Illustrates a fundamental supervised learning algorithm used for classification.
*   **Probability**: Visualizes conditional probabilities, Bayes' Theorem, and how likelihoods inform classification.
*   **Data Visualization**: Employs interactive charts and graphs to represent data, distributions, and decision boundaries.
*   **Classification**: Demonstrates how data points are assigned to predefined categories based on learned probabilities.
