# Rule-Based Sentiment Analyzer 🚀
> A simple web application where users can input text, and the app will classify its sentiment (positive, negative, or neutral) based on pre-defined keyword lists and basic JavaScript logic. This project introduces the foundational concepts of natural language processing and rule-based AI without needing external APIs or complex machine learning models.

## Description
This project is a straightforward web application designed to classify the sentiment of user-provided text. By leveraging pre-defined lists of positive and negative keywords, it applies basic JavaScript logic to determine whether the input is positive, negative, or neutral. It serves as an excellent introduction to the core principles of natural language processing and rule-based artificial intelligence, all without requiring external APIs or complex machine learning frameworks.

## Features
*   **Intuitive Text Input:** Users can easily enter any desired text into a dedicated input area for analysis.
*   **Real-time Sentiment Classification:** Instantly classifies text as positive, negative, or neutral upon submission.
*   **Rule-Based Logic:** Employs a transparent, keyword-driven system for sentiment detection, making the classification process easy to understand.
*   **Client-Side Processing:** All analysis is performed directly in the browser using JavaScript, ensuring privacy and eliminating server-side overhead.
*   **Clear Result Display:** Presents the sentiment analysis result prominently and clearly to the user.
*   **No External Dependencies:** Operates entirely self-contained, requiring no external APIs, libraries, or complex build steps.
*   **Educational Foundation:** Provides a practical, hands-on example of foundational NLP and AI concepts.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript (ES6+)

## Key Concepts Demonstrated
*   **HTML:** Used for structuring the web page, creating the text input area, and displaying the sentiment analysis results.
*   **CSS:** Applied for styling the user interface, ensuring a clean, responsive, and visually appealing presentation.
*   **JavaScript:** The core language for implementing the sentiment analysis logic, handling user input, performing text processing, and dynamically updating the DOM.
*   **Text Analysis:** Involves processing raw text input, identifying individual words, and comparing them against predefined keyword lists.
*   **Sentiment Analysis:** The primary objective of the application, classifying the emotional tone (positive, negative, neutral) of the input text.
*   **Rule-Based Logic:** Utilizes a set of predefined rules (keyword matching, scoring) to make decisions and classify sentiment, demonstrating a fundamental AI approach.
