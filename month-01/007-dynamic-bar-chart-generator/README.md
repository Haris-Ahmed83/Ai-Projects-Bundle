# Dynamic Bar Chart Generator 🚀
> Build a web application that allows users to input simple numerical data and corresponding labels. The app will then instantly generate and display an interactive bar chart based on the provided data, with options for basic customization like colors.

## Description
This project delivers a responsive web application designed for dynamic data visualization. Users can easily input numerical data points along with their corresponding labels, and the application will immediately render an interactive bar chart. It provides a straightforward way to visualize simple datasets without any external libraries or complex setups.

## Features
*   **Intuitive Data Input**: Simple forms for users to enter numerical values and text labels.
*   **Instant Chart Generation**: Bar chart is dynamically created and displayed as soon as data is provided.
*   **Interactive Bar Charts**: Hover effects or click interactions for individual bars to display details (e.g., value).
*   **Basic Customization Options**: Users can choose colors for the bars or chart elements.
*   **Responsive Design**: The application adapts to various screen sizes for a consistent user experience.
*   **Error Handling**: Basic validation for input to ensure data integrity.
*   **Clear Visual Representation**: Easily understandable bar charts for quick data interpretation.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript (Vanilla JS)

## Key Concepts Demonstrated
*   **Data Visualization**: Effectively transforming raw numerical data into an easily digestible graphical format (bar charts).
*   **Interactive UI**: Creating a user interface that responds dynamically to user input and provides an engaging experience, such as instant chart updates and hover effects.
*   **Vanilla JS**: Implementing all core logic, DOM manipulation, and interactive features using plain JavaScript without relying on external frameworks or libraries.
