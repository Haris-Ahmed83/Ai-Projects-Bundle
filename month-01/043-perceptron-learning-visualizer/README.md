# Perceptron Learning Visualizer 🚀
> An interactive web application demonstrating the fundamental workings of a perceptron. Users can add data points, adjust parameters, and visualize the learning process in real-time.

## Description
This interactive web application provides a hands-on experience to understand the core principles of a perceptron, a foundational element in neural networks. Users can dynamically add data points, adjust learning parameters, and visualize the real-time evolution of the perceptron's decision boundary as it learns to classify. It's an excellent tool for grasping basic machine learning concepts through direct interaction.

## Features
*   **Interactive Data Point Creation:** Easily add positive and negative data points to the canvas with a click.
*   **Dynamic Parameter Adjustment:** Control the perceptron's learning rate and iteration speed for customized experiments.
*   **Real-time Decision Boundary Visualization:** Witness the perceptron's separating hyperplane adjust with each learning step.
*   **Misclassification Highlighting:** Clearly see which data points are currently misclassified by the perceptron.
*   **Step-by-Step Learning Simulation:** Option to advance the learning process one iteration at a time or run continuously.
*   **Reset Functionality:** Clear the canvas and perceptron state to start a new experiment.
*   **Performance Metrics:** View the current number of iterations and misclassified points.
