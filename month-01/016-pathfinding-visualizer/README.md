# Pathfinding Visualizer 🚀
> An interactive web application allowing users to visualize various pathfinding algorithms like Dijkstra's or A*. Users can draw obstacles on a grid, set start and end points, and observe how the algorithm finds the shortest path.

## Description
This interactive web application provides a dynamic platform for understanding fundamental pathfinding algorithms. Users can actively engage by drawing obstacles, defining start and end points on a grid, and then observing in real-time how algorithms like Dijkstra's or A* efficiently navigate to discover the shortest path. It serves as an excellent tool for learning and experimenting with algorithmic logic in a visual context.

## Features
*   Visualize popular pathfinding algorithms (e.g., Dijkstra's, A*).
*   Interactive grid system allowing users to draw and erase custom obstacles.
*   Ability to set and reposition custom start and end nodes dynamically.
*   Real-time step-by-step visualization of the algorithm's exploration process.
*   Clear grid functionality to reset the board and start a new visualization.
*   Highlights the shortest path found once the algorithm completes its search.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript (Vanilla)

## Key Concepts Demonstrated
*   **Algorithms**: Practical implementation and visualization of classic pathfinding algorithms (e.g., Dijkstra's, A*, BFS).
*   **Data Structures**: Utilization of fundamental data structures such as priority queues (for Dijkstra's/A*) or queues (for BFS) to manage nodes during search.
*   **Interactive Visualization**: Dynamic rendering of grid states, node traversal, and path discovery, providing a clear understanding of algorithmic flow.
*   **Grid Systems**: Management and manipulation of a 2D grid structure to represent the search space, obstacles, and path.
