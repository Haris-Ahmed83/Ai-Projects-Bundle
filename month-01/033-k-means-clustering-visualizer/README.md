# K-Means Clustering Visualizer 🚀
> An interactive web application that visualizes the K-Means clustering algorithm. Users can generate data

## Description
This interactive web application provides a dynamic platform for understanding the K-Means clustering algorithm. Users can generate custom datasets and observe the step-by-step process of data points being assigned to clusters and centroids iteratively adjusting their positions. It serves as an excellent educational tool for grasping core concepts of unsupervised machine learning.

## Features
*   **Interactive Data Generation:** Users can generate diverse datasets (e.g., random, clustered, custom-drawn) to test the algorithm under various conditions.
*   **Adjustable K-Value:** Easily set the desired number of clusters (K) to explore its impact on the clustering outcome.
*   **Step-by-Step Algorithm Execution:** Observe the K-Means algorithm progress iteration by iteration, highlighting centroid updates and data point reassignments.
*   **Real-time Visualization:** Dynamically display data points, their assigned clusters, and the movement of centroids throughout the clustering process.
*   **Animated Clustering Process:** Enjoy a smooth animation that illustrates the convergence of centroids and the final cluster formations.
*   **Reset Functionality:** Quickly clear the canvas and reset parameters to start new experiments with fresh data.

*   **machine learning:** Provides a hands-on demonstration of a fundamental machine learning algorithm in action.
