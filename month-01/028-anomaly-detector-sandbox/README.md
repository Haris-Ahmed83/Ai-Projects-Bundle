# Anomaly Detector Sandbox 🚀
> This web app allows users to input numerical datasets and interactively visualize potential data anomalies. It identifies outliers based on configurable statistical rules (e.g., Z-score, IQR range, etc.).

## Description
This web application provides a hands-on environment for exploring data integrity and identifying unusual patterns within numerical datasets. Users can upload their own data or input values directly, then apply various statistical rules to detect outliers. The interactive visualizations offer immediate feedback, making it a powerful tool for understanding statistical deviations and fine-tuning anomaly detection parameters.

## Features
*   **Dataset Input**: Easily upload numerical datasets (e.g., CSV) or manually input data for analysis.
*   **Interactive Visualization**: Explore your data with dynamic charts and plots that clearly display data distribution and potential outliers.
*   **Configurable Anomaly Rules**: Define custom statistical thresholds (e.g., Z-score, IQR method, standard deviation) to tailor anomaly detection to your specific needs.
*   **Outlier Highlighting**: Clearly visualize identified anomalies directly on the plots for immediate insight into unusual data points.
*   **Statistical Insights**: Gain a better understanding of your dataset's properties and the statistical basis for anomaly detection.
*   **User-Friendly Interface**: An intuitive and responsive UI designed for easy interaction and dynamic data exploration.
*   **Real-time Feedback**: See the impact of rule changes and data adjustments instantly on the visualizations.
