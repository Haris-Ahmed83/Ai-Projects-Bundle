## Description
This interactive web application provides a hands-on approach to understanding linear regression. Users can intuitively add custom data points to a scatter plot, and the tool will automatically compute and visualize the best-fit linear regression line. It serves as an excellent educational resource for exploring statistical relationships and the foundational concepts behind predictive modeling.

## Features
*   **Interactive Data Input:** Add custom data points directly onto the scatter plot with a simple click.
*   **Real-time Regression Calculation:** Instantly calculates and updates the linear regression line as data points are added or modified.
*   **Visual Best-Fit Line:** Clearly displays the calculated linear regression line superimposed on the scatter plot.
*   **Regression Equation Display:** Shows the mathematical equation of the best-fit line (e.g., `y = mx + b`).
*   **Key Statistical Metrics:** Provides relevant statistical insights, such as the R-squared value, to quantify model fit.
*   **Clear/Reset Functionality:** Easily clear all existing data points and reset the plot to start a new exploration.

## Tech Stack
*   HTML5
*   CSS3

## Key Concepts Demonstrated
*   **Data Visualization:** Interactive scatter plots and line graphs to represent relationships between variables.
*   **Linear Regression:** Practical implementation and visual explanation of the least squares method to find the best-fit line.
*   **Statistics:** Understanding concepts like correlation, slope, y-intercept, and R-squared.
*   **Machine Learning Fundamentals:** Introduction to predictive modeling, feature-target relationships, and basic supervised learning algorithms.
