# K-Means Clustering Sandbox 🚀
> An interactive web application where users can draw data points on a canvas, set the number of clusters (K), and visualize the K-Means algorithm in action. Watch as cluster centroids adjust and data points are re-assigned, providing an intuitive understanding of this fundamental machine learning concept.

## Description
This project is an interactive web application designed to visually explain the K-Means clustering algorithm. Users can dynamically draw data points on a canvas, specify the desired number of clusters (K), and observe the algorithm's iterative process. It offers an intuitive demonstration of how cluster centroids adjust and data points are reassigned, enhancing understanding of this core machine learning concept.

## Features
*   **Interactive Data Point Drawing**: Easily add data points to the canvas with a click or drag.
*   **Dynamic K-Value Adjustment**: Set the number of clusters (K) before or during the simulation.
*   **Real-time Algorithm Visualization**: Observe the K-Means algorithm's iterations as centroids move and data points are re-clustered.
*   **Animated Progression**: Watch the algorithm unfold step-by-step or continuously with clear visual feedback.
*   **Visual Representation of Clusters**: Data points are color-coded to their assigned clusters for clear differentiation.
*   **Intuitive Learning Experience**: Gain a practical and visual understanding of how K-Means clustering works.
*   **Reset and Clear Canvas Options**: Easily clear all data points and reset the simulation to start anew.

## Key Concepts Demonstrated
*   **K-Means**: The core algorithm at the heart of the application, visually explained.
*   **Clustering**: Demonstrates the unsupervised learning task of grouping similar data points.
