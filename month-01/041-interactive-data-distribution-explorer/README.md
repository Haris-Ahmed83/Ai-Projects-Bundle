# Interactive Data Distribution Explorer 🚀
> Visualize various statistical distributions (e.g., Normal, Uniform, Exponential) by adjusting their parameters in real-time. Users can generate random samples and see how

## Description
This web application provides an interactive platform to explore fundamental statistical distributions. Users can dynamically adjust parameters for distributions like Normal, Uniform, and Exponential, instantly observing how these changes impact their shape and characteristics. It also allows for generating random samples to visualize their distribution and understand statistical concepts intuitively.

## Features
*   Interactive visualization of multiple statistical distributions (e.g., Normal, Uniform, Exponential).
*   Real-time parameter adjustment for each distribution (e.g., mean/standard deviation for Normal, min/max for Uniform).
*   Dynamic updates to distribution curves as parameters change.
*   Ability to generate and visualize random samples from the selected distribution.
*   Graphical representation of sample data alongside theoretical distribution.
*   Clear and intuitive user interface for exploring statistical concepts.
*   No backend or complex setup required; purely client-side functionality.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript

## Key Concepts Demonstrated
*   **Statistics:** Understanding of central tendency, dispersion, probability density functions, and the properties of common distributions.
*   **Data Visualization:** Effective graphical representation of statistical data and distributions for intuitive understanding.
*   **Probability:** Exploration of probability distributions, random sampling, and the likelihood of events.
*   **JavaScript:** Client-side scripting for interactive UI elements, real-time calculations, and dynamic DOM manipulation.
