# Gradient Descent Visualizer 🚀

## Description
This web application provides an interactive visualization of the gradient descent algorithm. It allows users to gain a practical understanding of how this fundamental machine learning optimization technique works by dynamically observing its iterative process. By adjusting key parameters, users can explore the impact of learning rate and initial conditions on the algorithm's convergence path towards a function's minimum.

## Features
*   **Interactive Parameter Adjustment**: Dynamically change the learning rate and initial starting point.
*   **Real-time Visualization**: Observe the gradient descent path update instantly as parameters are tweaked.
*   **Function Minimum Tracking**: Clearly see the optimizer's progress towards the minimum of a predefined simple function.
*   **Step-by-Step Path Display**: Visualize each step taken by the algorithm on the function's landscape.
*   **Clear Concept Illustration**: Provides an intuitive way to understand convergence, divergence, and local minima.
*   **User-Friendly Interface**: Simple and accessible design for easy interaction and understanding.
*   **Performance Metrics**: Potentially display the current cost/error at each step (if implemented, otherwise omit).
