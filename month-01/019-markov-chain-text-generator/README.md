# Markov Chain Text Generator 🚀
> Provide a text corpus (e.g., a book or article), and the application will learn the probability

## Description
This web application implements a Markov Chain Text Generator, allowing users to create unique text based on a provided corpus. By analyzing the input text, the application learns the statistical probabilities of word sequences, enabling it to generate new, coherent, and contextually relevant passages. It's a fascinating demonstration of how simple statistical models can produce complex outputs.

## Features
*   Accepts user-provided text as a corpus for analysis.
*   Dynamically learns word transition probabilities from the input.
*   Generates new text based on the learned Markov model.
*   Outputs text with a user-defined length or word count.
*   Provides an interactive and intuitive web interface for input and generation.
*   Showcases the fundamental principles of probabilistic language modeling.
*   Operates entirely client-side, requiring no server interaction.
