# Location Data Mapper 🚀
> A web tool that enables users to visualize custom location-based data on an interactive map. Users can input coordinates and associated data to see points plotted, offering an engaging way to explore geographical datasets.

## Description
This web tool provides an intuitive platform for users to bring their geographical datasets to life. By simply inputting coordinates and any associated information, users can dynamically plot custom points onto an interactive map, transforming raw data into engaging visual insights. It's designed for easily exploring and understanding location-based information.

## Features
*   Input custom latitude and longitude coordinates for plotting.
*   Associate additional descriptive data with each plotted point.
*   Dynamically visualize custom data points on an interactive world map.
*   Pan, zoom, and explore the map with intuitive Leaflet.js controls.
*   Clear all plotted points to start a new visualization session.
*   Simple and user-friendly interface for data entry and map interaction.
*   Leverages modern web technologies for a smooth and responsive mapping experience.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript (ES6+)
*   Leaflet.js (Interactive Mapping Library)

## Key Concepts Demonstrated
*   **Geospatial Data:** Handling and processing latitude and longitude coordinates to define specific geographical locations for visualization.
*   **Mapping:** Implementation and display of an interactive map interface, providing geographical context for user data.
*   **Data Visualization:** Representing abstract data points visually on a map to reveal spatial patterns, distributions, and insights.
*   **Leaflet.js:** Practical application of a leading open-source JavaScript library for creating mobile-friendly interactive maps efficiently.
*   **JavaScript:** Core programming language used for all client-side logic, handling user input, dynamically interacting with the map, and data manipulation.
