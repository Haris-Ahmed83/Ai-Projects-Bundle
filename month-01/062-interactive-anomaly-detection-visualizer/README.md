## Description
This interactive web application provides a user-friendly interface for exploring anomaly detection within simple datasets. Users can input a list of numbers and visualize potential outliers, making statistical analysis accessible and engaging. It aims to demonstrate fundamental concepts of identifying unusual data points through visual means.

## Features
*   **Input Handling**: Allows users to easily input simple datasets (e.g., a list of numbers).
*   **Data Visualization**: Generates interactive plots to visualize the input data distribution.
*   **Anomaly Highlighting**: Clearly marks and highlights detected anomalies directly on the data visualization.
*   **Statistical Insights**: Provides basic statistical summaries of the dataset, aiding in understanding data characteristics.
*   **Interactive Controls**: Offers interactive elements to explore how different parameters might affect anomaly detection.
*   **User-Friendly Interface**: Features a clean and intuitive UI for an engaging user experience.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript

## Key Concepts Demonstrated
*   **Data Visualization**: Illustrates how raw numerical data can be transformed into meaningful graphical representations for easier interpretation.
*   **Anomaly Detection**: Showcases fundamental techniques and principles for identifying unusual patterns or outliers within a given dataset.
*   **Statistics**: Applies basic statistical methods (e.g., mean, standard deviation, quartiles) to analyze data and quantitatively define anomalies.
*   **Interactive UI**: Demonstrates the design and implementation of user interface elements that respond to user input, enhancing engagement and data exploration.
