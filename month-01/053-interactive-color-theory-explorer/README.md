# Interactive Color Theory Explorer 🚀
> An interactive web tool allowing users to select a base color and visually

## Description
This interactive web tool empowers users to select a base color and visually explore fundamental color theory principles. It serves as an educational and practical resource for designers, developers, and artists to understand color relationships, generate harmonious palettes, and apply them effectively in their projects.

## Features
*   **Intuitive Base Color Selection**: Easily pick a base color using a color picker or by inputting HEX, RGB, or HSL values.
*   **Dynamic Color Scheme Generation**: Instantly generate and visualize various color palettes, including complementary, analogous, triadic, tetradic, and monochromatic schemes.
*   **Multiple Color Model Displays**: View selected colors and their generated schemes simultaneously in HEX, RGB, and HSL formats.
*   **Interactive Color Adjustments**: Fine-tune generated colors by manipulating hue, saturation, and lightness sliders for precise control.
*   **Accessibility Insights**: Integrate basic contrast ratio checks to help ensure generated palettes meet web accessibility standards.
*   **Copy to Clipboard Functionality**: Quickly copy any displayed color's HEX, RGB, or HSL code for immediate use in other applications.
*   **Responsive User Interface**: Enjoy a seamless and consistent experience across different devices and screen sizes.

## Tech Stack
*   HTML5
*   CSS3
*   Vanilla JavaScript

## Key Concepts Demonstrated
*   **Color Theory**: Visual exploration and practical application of color relationships, harmonies, and schemes (complementary, analogous, triadic, etc.).
*   **HSL (Hue, Saturation, Lightness)**: Understanding and manipulating colors through the HSL model for intuitive adjustments and color generation.
*   **RGB (Red, Green, Blue)**: Displaying and converting colors using the additive RGB model, fundamental for digital displays.
*   **HEX (Hexadecimal)**: Representing and utilizing colors in the concise hexadecimal format, a standard in web development.
*   **Web Design**: Implementation of a clean, intuitive, and responsive user interface for an engaging and accessible web application.
*   **Accessibility**: Consideration for users with varying needs through features like color contrast checking and clear information presentation.
*   **Vanilla JS**: Building robust interactive functionality and dynamic content manipulation entirely with plain JavaScript, without external libraries.
