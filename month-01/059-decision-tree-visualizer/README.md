# Decision Tree Visualizer 🚀
> An interactive web application that visualizes the structure and decision-making process of a simple decision tree. Users can explore how data is split at each node to reach a classification or regression outcome, illustrating a core machine learning concept.

## Description
This web application offers an engaging way to understand decision trees, a fundamental machine learning algorithm. It provides an interactive visualization where users can observe how raw data is systematically split at each decision node, ultimately leading to a final classification or regression prediction. The tool aims to demystify the internal workings of decision trees, making complex machine learning concepts accessible and intuitive.

## Features
*   Interactive visualization of the decision tree's hierarchical structure.
*   Dynamic display of how data is partitioned at each decision node.
*   Clear illustration of classification or regression outcomes at leaf nodes.
*   User-friendly interface for effortless exploration of tree paths and splits.
*   Highlights the impact of different feature thresholds on data segmentation.
*   No external dependencies or complex setup required for immediate use.
*   Serves as an educational tool for grasping core machine learning principles visually.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript (Vanilla JS)

## Key Concepts Demonstrated
*   **Machine Learning**: Showcases a fundamental supervised learning algorithm in action.
*   **Data Visualization**: Employs interactive graphics to represent complex data structures and decision processes.
*   **Decision Trees**: Provides a visual explanation of the algorithm's structure, node splits, and prediction logic.
*   **Interactive Graphics**: Enables users to dynamically explore and engage with the visualization to deepen understanding.
