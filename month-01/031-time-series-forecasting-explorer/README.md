# Time Series Forecasting Explorer 🚀
> An interactive tool where users can upload or input time series data. It visualizes the data and allows users to apply and compare simple forecasting methods like moving average and exponential smoothing, displaying the original data alongside the predictions.

## Description
This interactive web application provides a hands-on environment for exploring time series data. Users can easily upload their own datasets or input data directly, visualize trends, and apply fundamental forecasting methods like Moving Average and Exponential Smoothing. It's designed to make complex time series concepts accessible, allowing for direct comparison between original data and generated predictions.

## Features
*   **Flexible Data Input**: Upload time series data from files (e.g., CSV) or input data points manually.
*   **Dynamic Data Visualization**: Interactive charts display the original time series data, highlighting trends and patterns.
*   **Simple Forecasting Methods**: Apply core methods such as Moving Average and Exponential Smoothing.
*   **Parameter Customization**: Adjust method-specific parameters (e.g., window size for Moving Average, alpha for Exponential Smoothing) to observe their impact.
*   **Real-time Prediction Overlay**: View generated forecasts plotted directly alongside the original time series data.
*   **Comparative Analysis**: Easily compare the performance and outputs of different forecasting methods.
*   **Intuitive User Interface**: A clean and straightforward interface designed for ease of use and exploration.

## Tech Stack
*   **HTML**: For structuring the web application content.
*   **CSS**: For styling and layout of the user interface.
*   **JavaScript**: For all interactive elements, data processing, forecasting algorithm implementations, and dynamic visualizations.

## Key Concepts Demonstrated
*   **Time Series Analysis**: Understanding and processing sequential data points indexed in time.
*   **Data Visualization**: Representing complex data in graphical formats for easier interpretation.
*   **Predictive Modeling**: Using historical data to make informed predictions about future values.
*   **Moving Average**: A basic forecasting technique that smooths out short-term fluctuations to highlight longer-term trends or cycles.
*   **Exponential Smoothing**: A forecasting method that assigns exponentially decreasing weights to older observations.
