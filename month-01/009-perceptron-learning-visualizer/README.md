# Perceptron Learning Visualizer 🚀
> Build an interactive web application that visualizes a single perceptron learning to classify 2D data points. Users can add new positive or negative points and observe how the perceptron's decision boundary adjusts in real-time.

## Description
This interactive web application provides a hands-on experience with the fundamental principles of machine learning by visualizing a single perceptron. Users can actively participate in the learning process, adding custom 2D data points (positive or negative) to the canvas. The application then dynamically demonstrates how the perceptron's decision boundary iteratively adjusts to correctly classify these points in real-time.

## Features
*   **Interactive Data Point Creation:** Users can add positive (+) or negative (-) data points to the 2D canvas with a simple click.
*   **Real-time Decision Boundary Adjustment:** Observe the perceptron's decision boundary (a line) dynamically shifting as it learns from new data.
*   **Visual Representation of Learning:** Clearly see the perceptron's weights and bias being updated with each iteration of the learning algorithm.
*   **Live Classification Feedback:** Data points are re-classified in real-time based on the current decision boundary, highlighting misclassified points.
*   **Start/Stop Learning Control:** Pause or resume the perceptron's learning process to analyze specific stages or iterations.
*   **Reset Functionality:** Clear all data points and reset the perceptron to its initial state for a fresh start.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript (ES6+)
*   Canvas API

## Key Concepts Demonstrated
*   **Machine Learning:** Illustrates supervised learning through the perceptron algorithm, a foundational machine learning model.
*   **Neural Networks:** Provides a visual understanding of the simplest neural network unit – a single perceptron.
*   **Data Visualization:** Uses graphical elements to represent data points, the decision boundary, and the learning process effectively.
*   **Interactive Simulation:** Enables users to directly influence the simulation by adding data, observing immediate feedback and real-time adjustments.
