# Central Limit Theorem Visualizer 🚀
> An interactive web tool to visually demonstrate the Central Limit Theorem. Users can simulate sampling from various base distributions (e.g., uniform, exponential), calculate sample means, and observe how their distribution progressively forms a normal curve, even if the original distribution is not normal.

## Description
This project provides an interactive web application designed to offer a clear, visual demonstration of the Central Limit Theorem. It allows users to simulate the process of drawing multiple samples from diverse non-normal distributions, such as uniform or exponential. The tool then dynamically plots the distribution of these sample means, illustrating its convergence towards a normal distribution, irrespective of the original data's shape.

## Features
*   Select from various base distributions (e.g., Uniform, Exponential, Skewed) for initial data generation.
*   Adjust the sample size (`n`) to observe its direct impact on the characteristics of the sample means distribution.
*   Control the number of samples drawn to progressively build and visualize the distribution of sample means.
*   Real-time graphical representation of the original population distribution and the evolving distribution of sample means.
*   Interactive histograms to clearly display the frequency distribution of data.
*   Display key statistical metrics (mean, standard deviation) for both the base distribution and the distribution of sample means.
*   Reset functionality to easily start new simulations with different parameters and distributions.
