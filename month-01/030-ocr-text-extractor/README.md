## Description
The OCR Text Extractor is a user-friendly web application designed to effortlessly extract text from images. Users can upload an image file, and the application processes it directly in the browser to identify and display any embedded text. This client-side approach prioritizes speed and user privacy, as images are never sent to a server for processing.

## Features
*   Upload images easily via a drag-and-drop interface or file input.
*   Automatically detect and extract text from various image formats (e.g., JPEG, PNG).
*   Display extracted text in a clear, accessible, and editable text area.
*   Copy extracted text to the clipboard with a dedicated button.
*   Clear current image and extracted text to process a new image.
*   Perform all OCR operations entirely in the browser, ensuring data privacy and offline capability.
*   Provides real-time progress feedback during the OCR process.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript (ES6+)
*   Tesseract.js (Client-side OCR library)

## Key Concepts Demonstrated
*   **Optical Character Recognition (OCR)**: Practical application of OCR technology to convert image-based text into machine-readable text using a JavaScript library directly in the browser.
*   **Image Processing**: Handling image uploads, displaying image previews, and preparing image data for OCR analysis without server-side intervention.
*   **JavaScript Libraries**: Effective utilization of a powerful third-party JavaScript library (Tesseract.js) to extend native browser capabilities and perform complex tasks like text recognition.
