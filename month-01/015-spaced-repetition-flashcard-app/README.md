# Spaced Repetition Flashcard App 🚀
> Build an interactive web application that helps users learn and memorize information using the spaced repetition technique. Users can create custom flashcard

## Description
This interactive web application empowers users to effectively learn and memorize information through the proven spaced repetition technique. Users can create personalized sets of flashcards, and the app intelligently schedules reviews based on their learning progress, ensuring optimal retention. It's designed to make learning more efficient and engaging.

## Features
*   **Custom Flashcard Creation:** Easily create and manage your own sets of flashcards with questions and answers.
*   **Spaced Repetition Algorithm:** Intelligently schedules card reviews based on your performance to maximize long-term memory retention.
*   **Interactive Review Interface:** A user-friendly interface for reviewing flashcards, allowing users to mark difficulty (e.g., easy, medium, hard).
*   **Local Storage Persistence:** All your flashcards and learning progress data are saved directly in your browser, ensuring data is available across sessions.
*   **Learning Progress Tracking:** Monitors and displays your review history and performance for individual flashcards.
*   **Simple & Intuitive UI:** A clean and straightforward user interface designed for ease of use.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript

## Key Concepts Demonstrated
*   **Spaced Repetition:** Implementation of a learning algorithm that schedules future reviews of flashcards at increasing intervals based on user performance, optimizing memory retention.
*   **Flashcards:** Core functionality enabling users to create, manage, and interact with digital flashcards, each comprising a question and an answer.
*   **Local Storage:** Utilization of the browser's `localStorage` API to persistently store user-created flashcards and their associated learning data directly on the client side.
*   **Data Tracking:** Mechanisms to record and manage performance metrics (e.g., last reviewed date, review count, ease factor) for each flashcard, which informs the spaced repetition algorithm.
*   **Learning Algorithm:** Integration of a computational logic (e.g., a derivative of the SM-2 algorithm) to dynamically adjust the intervals between flashcard reviews based on user input and past performance.
