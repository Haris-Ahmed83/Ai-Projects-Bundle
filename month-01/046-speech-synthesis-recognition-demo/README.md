# Speech Synthesis & Recognition Demo 🚀
> A web application showcasing the browser's Web Speech API. Users can input text to have it spoken aloud by various voices, and also use their microphone

## Description
This web application provides an interactive demonstration of the browser's powerful Web Speech API. Users can effortlessly convert typed text into spoken words using various voices, and conversely, leverage their microphone to transcribe spoken input into text. It serves as a practical showcase for integrating advanced speech functionalities directly within a web browser, enhancing user interaction and accessibility.

## Features
*   **Text-to-Speech (Synthesis):** Convert any user-inputted text into spoken audio.
*   **Voice Selection:** Choose from a variety of available voices and languages provided by the browser.
*   **Speech-to-Text (Recognition):** Accurately transcribe spoken words from the user's microphone into text.
*   **Real-time Recognition Display:** View transcribed text dynamically as it's being recognized.
*   **Intuitive User Interface:** Simple controls for starting, stopping, and managing speech synthesis and recognition.
*   **Browser Compatibility Checks:** Provides feedback for unsupported browsers or missing microphone access.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript
*   Web Speech API

## Key Concepts Demonstrated
*   **Web Speech API:** Directly utilized for both speech synthesis (`SpeechSynthesisUtterance`, `speechSynthesis`) and speech recognition (`SpeechRecognition`) to enable voice interactions.
*   **Natural Language Processing:** Demonstrated indirectly through the browser's underlying speech processing engines that interpret and generate human language, making sense of spoken words and converting text into natural-sounding speech.
*   **Accessibility:** Enhances web accessibility by providing alternative input (voice commands) and output (spoken content) methods, catering to users with diverse needs.
*   **JavaScript:** The core programming language used to orchestrate all interactions, manage the Web Speech API, dynamically update the user interface, and handle event listeners.
