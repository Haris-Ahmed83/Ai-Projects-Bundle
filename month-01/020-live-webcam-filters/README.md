# Live Webcam Filters 🚀
> Access your webcam feed and apply various client-side visual filters (grayscale, sepia,

## Description
This project provides a dynamic web application that allows users to interact with their live webcam feed directly within the browser. It demonstrates the power of client-side web technologies to capture video input and apply a variety of real-time visual filters, transforming the raw feed into artistic or stylized outputs like grayscale and sepia, all without server-side processing.

## Features
*   Seamless access to the user's default webcam feed with appropriate permissions.
*   Application of multiple client-side visual filters (e.g., grayscale, sepia, invert, brightness).
*   Real-time filter processing and display, ensuring no noticeable lag.
*   Intuitive controls to switch between different filters instantly.
*   Option to revert to the original, unfiltered webcam feed.
*   Entirely browser-based operation, requiring no backend server or complex setup.
*   Leverages modern web APIs for a rich interactive experience.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript
*   WebRTC API
*   Canvas API

## Key Concepts Demonstrated
*   **WebRTC:** Utilized for securely accessing and streaming live video from the user's webcam, handling media permissions and stream management.
*   **Canvas API:** Employed for rendering the video stream frame-by-frame and performing pixel-level manipulation for filter effects and drawing.
*   **Image processing:** Implementation of algorithms directly in JavaScript to alter image data (e.g., converting RGB to grayscale, adjusting color channels for sepia, inverting colors).
*   **Real-time effects:** Demonstrates how to apply visual transformations instantly as new video frames are captured, creating a dynamic and interactive experience.

## Getting Started
- Open `index.html` in your browser
