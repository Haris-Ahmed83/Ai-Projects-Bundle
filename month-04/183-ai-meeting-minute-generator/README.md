# AI Meeting Minute Generator 🚀
> This web application transcribes live audio or uploaded recordings of meetings into text. It then uses AI to summarize key discussions

## Description
This web application offers an intelligent solution for meeting management by transcribing live audio or uploaded recordings into accurate text. Leveraging advanced AI, it then processes these transcripts to generate concise summaries, highlighting key discussions and actionable insights. It aims to streamline the process of documenting meetings and extracting essential information efficiently.

## Features
*   **Live Audio Transcription**: Real-time conversion of spoken words from ongoing meetings into text.
*   **Audio File Upload**: Ability to upload pre-recorded audio files for transcription.
*   **AI-Powered Summarization**: Intelligent generation of concise summaries, extracting key points and discussions.
*   **Key Discussion Extraction**: Identifies and highlights critical topics and decisions made during meetings.
*   **User-Friendly Interface**: Intuitive design for easy navigation and interaction.
*   **Efficient Meeting Documentation**: Streamlines the process of creating meeting minutes.
*   **Cross-Browser Compatibility**: Accessible across various modern web browsers.

## Tech Stack
*   React (Frontend UI Library)
*   WebRTC (for Live Audio Capture)
*   Speech-to-Text API/Service (for transcription)
*   Natural Language Processing (NLP) API/Service (for text analysis and summarization)
*   AI/Machine Learning Models (underlying summarization capabilities)
*   HTML5, CSS3, JavaScript

## Key Concepts Demonstrated
*   **AI**: Application of artificial intelligence for intelligent text summarization and insight generation from meeting transcripts.
*   **Speech-to-Text**: Real-time and offline conversion of spoken language into written text, forming the foundation of the transcription feature.
*   **Natural Language Processing (NLP)**: Utilization of NLP techniques to understand, interpret, and process human language from transcripts for meaningful summarization.
*   **Summarization**: Automated generation of concise overviews of longer texts, focusing on key information and discussions from meetings.
*   **WebRTC**: Implementation of Web Real-Time Communication for capturing and streaming live audio directly within the browser.
*   **React**: Development of a dynamic and responsive user interface using the React JavaScript library, ensuring a smooth user experience.
