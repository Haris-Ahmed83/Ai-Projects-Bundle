## Description
Upload any image and transform it with the artistic style of famous paintings or other uploaded styles. This app leverages advanced AI and machine learning models to seamlessly transfer artistic characteristics, providing users with a unique creative tool. Experience the magic of turning ordinary photos into masterpieces with just a few clicks.

## Features
*   **Intuitive Image Upload**: Easily upload your desired image for transformation.
*   **Pre-defined Style Library**: Choose from a curated selection of famous artistic styles.
*   **Custom Style Upload**: Personalize your experience by uploading your own reference style images.
*   **Real-time Style Transfer**: Witness the artistic transformation applied to your image almost instantly.
*   **High-Quality Output**: Generate stunning, high-resolution styled images.
*   **Download Transformed Images**: Save your newly created masterpieces directly to your device.
*   **User-Friendly Interface**: A clean and responsive design ensures a smooth and enjoyable user experience.

## Tech Stack
*   **Frontend**: HTML5, CSS3, JavaScript (ES6+)
*   **API Communication**: Fetch API
