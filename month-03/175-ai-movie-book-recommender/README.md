# AI Movie & Book Recommender 🚀
> This project helps users discover new movies and books based on their preferences. Users can input genres

## Description
This web application provides a personalized discovery experience for movies and books. By simply inputting preferred genres, users can effortlessly find new titles tailored to their tastes. It leverages external APIs to fetch a diverse range of content and presents it through an intuitive interface.

## Features
*   **Genre-based Recommendations:** Receive tailored suggestions for movies and books by specifying preferred genres.
*   **Dynamic Content Display:** Instantly view search results for movies and books updated in real-time.
*   **Intuitive User Interface:** A clean and easy-to-navigate design ensures a smooth user experience.
*   **Separate Content Sections:** Dedicated sections for movie and book recommendations for clarity.
*   **Robust API Integration:** Seamlessly fetches data from external movie and book databases.
*   **Client-Side Data Filtering:** Efficiently processes and filters fetched data based on user input.
*   **Responsive Design:** Ensures a consistent and enjoyable experience across various devices.

## Tech Stack
*   HTML5
*   CSS3
*   JavaScript (ES6+)
*   The Movie Database (TMDb) API (for movies)
*   Google Books API (for books)

## Key Concepts Demonstrated
*   **Recommendation System:** Implemented through genre-based filtering and external API data retrieval, providing personalized content suggestions.
*   **API Integration:** Demonstrates fetching and processing data from third-party services like TMDb and Google Books APIs to enrich content.
*   **Data Filtering:** Shows how to effectively filter and display relevant data dynamically based on user-selected criteria (genres).
*   **Modern JavaScript:** Utilizes contemporary JavaScript features such as `async/await` for asynchronous operations, advanced DOM manipulation, and ES6+ syntax for a robust and efficient application.
